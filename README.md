# Дыхание — практика каждый день

PWA для дыхательных практик. Работает офлайн, ставится на домашний экран.

**Техники:** квадратное дыхание 4-4-4-4, дыхание 4-7-8, когерентное дыхание 5.5-5.5, спокойствие 4-6.

**Функции:** анимированный круг-проводник, длительность сессии 1–10 минут, звук и вибрация, счётчик серий (streak), офлайн-режим.

## Запуск локально

```
python3 -m http.server 8000
```

и открыть http://localhost:8000

## Стек

Чистый HTML/CSS/JS без зависимостей. Service worker для офлайна, Web Audio для звука, Vibration API, Wake Lock.
